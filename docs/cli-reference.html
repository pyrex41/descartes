CLI Reference

Complete command reference for descartes-cli.

Option Description

Execution Modes

Descartes has two distinct execution patterns, each optimized for different workflows:

Aspect descartes ralph descartes loop
Pattern Fresh context per task BAML-orchestrated iteration
Review Agent No (intentional for determinism) Yes (conditional on config)
Context Handoff Yes (at 60% window) No
BAML Usage None Heavy (4 functions)
Best For CI/CD, large task graphs Interactive development
Why Two Modes? The ralph command prioritizes determinism and parallelism for batch execution. The loop command uses BAML for intelligent decisions and includes an optional review agent for quality-critical work. Choose based on your workflow needs.

Commands

descartes ralph

Execute SCUD tasks with fresh context per task and wave-based parallelism. Best for batch execution and CI/CD.

Key Characteristics
  • Fresh context: Each task starts with clean agent session
  • Context handoff: Long tasks automatically hand off at 60% context window
  • No review agent: Uses backpressure validation instead (intentional for determinism)
  • Wave parallelism: Tasks in same wave run in configurable rounds

PRD Initialization

OptionDescription
--prd <PATH>Initialize tasks from PRD document
--tag <NAME>Tag name for new tasks (defaults to filename)
--num-tasks <N>Number of tasks to generate (default: 10)
--no-expandSkip task expansion
--no-check-depsSkip dependency validation

Task Selection

OptionDescription
--scud-tag <TAG>Execute tasks from existing SCUD tag

Spec Configuration

OptionDescription
--plan <PATH>Implementation plan document for context
--spec-file <PATH>Additional spec files (repeatable)
--max-spec-tokens <N>Token budget for specs (default: 5000)

Execution

OptionDescription
--harness <NAME>Harness: claude-code, opencode, codex
--model <NAME>Model override (opus, sonnet, etc.)
--verify <CMD>Validation command between waves
--round-size <N>Tasks per round (default: 5)
--no-validateSkip validation between waves
--dry-runShow execution plan without running
--working-dir <PATH>Working directory for agents

Examples

# Basic execution from SCUD tag
descartes ralph --scud-tag my-feature

# Full PRD-to-execution workflow
descartes ralph \
    --prd ./docs/feature.md \
    --tag feature-v1 \
    --plan ./docs/implementation.md \
    --verify "cargo test"

# Using OpenCode harness with Grok
descartes ralph \
    --scud-tag my-feature \
    --harness opencode \
    --model grok-code-fast-1

# Preview execution plan
descartes ralph --scud-tag my-feature --dry-run

descartes spawn

Manually spawn a subagent for a specific task.

descartes spawn <CATEGORY> "<PROMPT>"

Categories

CategoryDescriptionDefault Model
searcherFast parallel code searchsonnet
analyzerDeep code analysis (read-only)sonnet
builderCode implementationopus
validatorTest runner, backpressuresonnet
plannerTask breakdownopus

Examples

# Search for authentication code
descartes spawn searcher "Find all files related to user authentication"

# Analyze a specific module
descartes spawn analyzer "Analyze the error handling in src/api/"

# Implement a feature
descartes spawn builder "Add rate limiting to the /api/users endpoint"

descartes run

Run a single build iteration (one task from SCUD).

descartes run

descartes plan

Run a single planning iteration (analyze gaps, update task graph).

descartes plan

descartes loop

Run BAML-orchestrated iterations with optional review agent. Best for interactive development.

Key Characteristics
  • BAML decisions: Uses AI to decide next action (Continue/Replan/Complete/AskHuman)
  • 5-phase pattern: Parallel search → Builder → Review → Validator → Commit
  • Review agent: Optional code review (enable with always_review config)
  • Dynamic agent selection: BAML chooses searcher/builder categories
OptionDescription
--planRun in planning mode
-m, --max <N>Maximum iterations (0 = infinite)
# Run build mode until all tasks complete
descartes loop

# Run 5 planning iterations
descartes loop --plan --max 5

Review Agent Configuration

The review agent is conditional in loop mode:

# In descartes.toml
[ralph_loop]
always_review = true  # Enable review agent for all builds

# Or via task override (YAML frontmatter in task):
---
category: fast-builder
disable_review: true  # Skip review for this task
---

descartes waves

Display task waves computed from SCUD's dependency DAG.

descartes waves

# Output:
# Wave 1:
#   [1] Setup project structure
#   [2] Configure database
# Wave 2:
#   [3] Implement user model (depends: 2)
#   [4] Add API routes (depends: 1)

descartes next

Get the next ready task from SCUD.

descartes next

# Output:
# Task 3: Implement user model
# Status: pending
# Dependencies: [2] Configure database (done)

descartes complete

Mark a task as complete in SCUD.

descartes complete <TASK_ID>

# Example
descartes complete 3

descartes transcripts

List saved agent transcripts.

OptionDescription
--todayShow only today's transcripts
--session <ID>Filter by session ID
descartes transcripts --today

descartes show

Display a transcript in SCG format.

descartes show <SESSION_ID>

descartes replay

Replay a transcript with timing.

OptionDescription
--speed <N>Playback speed multiplier (default: 1.0)
# Normal speed replay
descartes replay abc123

# 2x speed
descartes replay abc123 --speed 2.0

descartes interactive

Start an interactive CLI session with slash commands.

descartes interactive
# or
descartes i

# Available commands:
# /plan   - Switch to planning mode
# /build  - Switch to building mode
# /status - Show current state
# /quit   - Exit

descartes skills

Manage skill prompt templates.

# List available skills
descartes skills list

# Initialize default skills
descartes skills init

# Force overwrite existing
descartes skills init --force

# Show a skill's prompt
descartes skills show review

descartes init

Initialize the .descartes/ directory in your project.

descartes init

descartes config

Show the current configuration.

descartes config

descartes harness

Show the active harness configuration.

descartes harness
