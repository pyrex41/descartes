GUI Guide

The Descartes GUI provides visual control over AI agent execution using an Iced-based desktop application.

Installation

# Install both CLI and GUI (GUI requires CLI library, but CLI binaries installed separately)
cargo install descartes-cli descartes-gui

# From source
cd descartes/descartes-gui
cargo build --release
CLI Not Included Installing the GUI does not install the descartes CLI binary. Run both cargo install commands to get full functionality.

System Dependencies

macOS: No additional dependencies required.

Linux:

sudo apt install libxkbcommon-dev libwayland-dev

Running the GUI

# Start the GUI
descartes-gui

# Or run from source
cargo run --release -p descartes-gui

The GUI reads task data from SCUD storage at .scud/tasks/tasks.scg. Ensure you have SCUD configured in your project:

cd your-project
scud warmup
descartes-gui

Views

Waves View

Displays tasks organized by parallel execution waves, computed from SCUD's dependency DAG.

  • Wave grouping: Tasks with satisfied dependencies are grouped into waves
  • Status display: Shows task ID, title, and current status (Pending, InProgress, Done)
  • One-click start: Start button on each pending task to begin agent execution
  • Refresh: Reload waves from SCUD storage

Agents View

Real-time control over running agents:

ControlDescription
PauseSuspends agent execution, buffering responses
ResumeContinues paused agent from where it left off
CancelTerminates agent execution, marks task for retry

Output View

Streaming display of agent output:

  • Real-time streaming: Output appears as the agent generates it
  • Completion markers: Clear indication when agent completes or errors
  • Scrollable history: Review full agent output session

Terminal Attach Mode

When running agents in a terminal multiplexer (Zellij, Tmux, Kitty), you can focus on a running agent's pane:

  1. Press 1-9 in the Ralph TUI to focus on that agent's pane
  2. Descartes detects your terminal type automatically
  3. Focus commands: zellij action focus-pane, tmux select-pane, kitty @ focus-window
Multiplexer Required Attach mode requires running Descartes in a terminal multiplexer. The GUI's Agents view provides Pause/Resume controls as an alternative for headless operation.

Workflow

Starting Tasks

  1. Open the GUI in a project with SCUD tasks
  2. The Waves view shows all tasks organized by dependency order
  3. Click Start on any pending task in Wave 1
  4. Switch to Output view to watch agent progress
  5. When Wave 1 completes, Wave 2 tasks become available

Controlling Execution

  1. While an agent is running, switch to the Agents view
  2. Click Pause to suspend execution
  3. Review the current state, check output
  4. Click Resume to continue, or Cancel to abort

Refreshing State

Click Refresh to reload tasks from SCUD. This is useful when:

  • You've modified tasks outside the GUI (via CLI)
  • Another process has updated task status
  • You want to sync with the latest SCUD state

Note on Testing The GUI uses the iced_test crate for headless testing. Due to a dependency issue with rfd 0.16 (never published to crates.io), local testing requires a patch in Cargo.toml. This patch is automatically removed during publishing.

Limitations

Current v0.1 limitations:

  • Agent spawning is functional but uses placeholder integration
  • No model configuration UI yet (planned for v0.2)
  • No context supplementation / file drop (planned for v0.3)
  • No tool call visualization (planned for v0.4)

Troubleshooting

GUI won't start

# Check SCUD is initialized
scud warmup

# Verify tasks exist
scud list

# Check for errors
RUST_LOG=debug descartes-gui

Tasks not loading

# Verify SCUD storage exists
ls .scud/tasks/

# Check file format
cat .scud/tasks/tasks.scg

Linux display issues

# Install Wayland dependencies
sudo apt install libxkbcommon-dev libwayland-dev

# Or try X11 backend
WAYLAND_DISPLAY= descartes-gui
