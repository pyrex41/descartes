Descartes

Visible AI agent orchestration with the Ralph Wiggum loop pattern

Get Started GitHub crates.io

Why Descartes?

Fresh Context Per Task

Each task gets a clean agent session. No accumulated history, no context drift. The Ralph Wiggum loop ensures deterministic, repeatable execution.

Full Visibility

Every subagent execution is captured in full. See exactly what each agent did, replay transcripts, and debug with complete context.

Wave-Based Parallelism

Tasks execute in dependency order computed from SCUD's DAG. Independent tasks run in parallel waves, dependent tasks wait.

Backpressure Validation

Run tests, lints, and builds between waves. Failed validation marks tasks for retry. No silent failures.

Multiple Harnesses

Use Claude Code (headless), OpenCode (TUI), or Codex (API). Switch harnesses with a flag, same workflow.

SCUD Integration

Built on SCUD's token-efficient SCG format. Parse PRDs into tasks, compute waves, track progress - all from the CLI.

Quick Start

Install

# Install CLI
cargo install descartes-cli

# Install GUI (optional)
cargo install descartes-gui

# Or build from source
git clone https://github.com/pyrex41/descartes
cd descartes && cargo build --release

Configure

# Set API key
export ANTHROPIC_API_KEY=sk-ant-...

# Initialize SCUD in your project
scud warmup

Run

# Execute tasks from a PRD
descartes ralph --prd ./docs/feature.md

# Or execute an existing SCUD tag
descartes ralph --scud-tag my-feature

# Preview execution plan
descartes ralph --scud-tag my-feature --dry-run
