Harness Configuration

Descartes supports multiple harnesses for interacting with AI models. Each harness provides a different execution environment with its own tradeoffs.

Overview

Harness Execution Best For Required
claude-code Headless CLI Automation, CI/CD Claude CLI, ANTHROPIC_API_KEY
opencode TUI with IPC Interactive development OpenCode, XAI_API_KEY
codex Direct API Custom integrations OPENAI_API_KEY

Selecting a Harness

# Via command line
descartes ralph --scud-tag feature --harness claude-code

# Via environment variable
export DESCARTES_HARNESS=opencode
descartes ralph --scud-tag feature

# Via config file (descartes.toml)
[harness]
default = "claude-code"

Claude Code Harness

Runs Claude CLI in headless mode via subprocess. Best for automated workflows.

Setup

# Install Claude CLI
npm install -g @anthropic-ai/claude-cli

# Set API key
export ANTHROPIC_API_KEY=sk-ant-api03-...

Configuration

# descartes.toml
[harness.claude_code]
model = "opus"           # opus, sonnet
working_dir = "."        # Working directory for agents
timeout = 300            # Max seconds per task

Usage

# Explicit harness selection
descartes ralph --scud-tag feature --harness claude-code

# With model override
descartes ralph --scud-tag feature --harness claude-code --model sonnet

How It Works

  1. Spawns claude -p "<prompt>" as subprocess
  2. Streams stdout/stderr back to Descartes
  3. Captures full response in transcript
  4. Closes subprocess when task completes
Best For CI/CD pipelines, automated task execution, batch processing. No interactive features.

OpenCode Harness

Connects to OpenCode's TUI via IPC. Best for interactive development with visual feedback.

Setup

# Install OpenCode
cargo install opencode

# Set API key (xAI/Grok models)
export XAI_API_KEY=xai-...

Configuration

# descartes.toml
[harness.opencode]
model = "grok-code-fast-1"    # Fast model for quick tasks
smart_model = "grok-2"        # Smart model for complex tasks
working_dir = "."

Usage

# Use OpenCode harness
descartes ralph --scud-tag feature --harness opencode

# With specific model
descartes ralph --scud-tag feature --harness opencode --model grok-2

How It Works

  1. Starts OpenCode process with IPC channel
  2. Sends prompts via stdin
  3. Receives responses via stdout
  4. OpenCode provides TUI visualization
Best For Interactive development where you want to see agent activity. Uses Grok models for fast iteration.

Codex Harness

Direct API calls to OpenAI. Best for custom integrations or when CLI tools aren't available.

Setup

# Set API key
export OPENAI_API_KEY=sk-...

Configuration

# descartes.toml
[harness.codex]
model = "gpt-4"
api_base = "https://api.openai.com/v1"    # Or custom endpoint
max_tokens = 4096

Usage

descartes ralph --scud-tag feature --harness codex --model gpt-4

How It Works

  1. Makes HTTP requests to OpenAI API
  2. Streams responses via SSE
  3. No subprocess management
Note The Codex harness doesn't have tool use capabilities. It's best for simple text generation tasks, not complex code changes.

Agent Categories

Descartes uses different models for different agent categories:

Category Claude Code OpenCode Tools
Searcher sonnet grok-code-fast-1 Read, Bash
Analyzer sonnet grok-code-fast-1 Read only
Builder opus grok-2 Read, Write, Edit, Bash
Validator sonnet grok-code-fast-1 Bash only
Planner opus grok-2 Read, Bash

Switching Harnesses Mid-Workflow

You can switch harnesses between tasks or runs:

# Start with fast harness for simple tasks
descartes ralph --scud-tag setup --harness opencode

# Switch to Claude for complex implementation
descartes ralph --scud-tag implementation --harness claude-code --model opus

Custom Harness Configuration

Full configuration file example:

# descartes.toml

# Default harness selection
[harness]
default = "claude-code"

# Claude Code configuration
[harness.claude_code]
model = "opus"
working_dir = "."
timeout = 300

# OpenCode configuration
[harness.opencode]
model = "grok-code-fast-1"
smart_model = "grok-2"
working_dir = "."

# Codex configuration
[harness.codex]
model = "gpt-4"
max_tokens = 4096

# Category-specific overrides
[categories.builder]
model = "opus"
tools = ["read", "write", "edit", "bash"]

[categories.searcher]
model = "sonnet"
tools = ["read", "bash"]

# Backpressure validation
[backpressure]
commands = ["cargo test", "cargo clippy"]
stop_on_failure = true

Troubleshooting

Claude Code harness fails to start

# Check Claude CLI is installed
claude --version

# Verify API key
echo $ANTHROPIC_API_KEY

# Test manually
claude -p "Hello, world"

OpenCode connection issues

# Check OpenCode is installed
opencode --version

# Verify xAI key
echo $XAI_API_KEY

# Check IPC socket
ls /tmp/opencode-*

Codex API errors

# Verify API key
echo $OPENAI_API_KEY

# Test API directly
curl https://api.openai.com/v1/models \
  -H "Authorization: Bearer $OPENAI_API_KEY"
